# SharpEdge Release

A clean Vercel-ready sports picks app with a resilient frontend and server-side API routes.

## Included
- Mobile-first dashboard
- NFL / NBA / MLB / Soccer filters
- Moneyline / spread / total markets
- Player props screen
- Confidence scores and model edge display
- Parlay builder
- Live board
- Pro subscription UI + Stripe Checkout route
- Account/Admin screens
- SportsGameOdds server-side integration with safe fallback data
- Health endpoint
- No secrets in browser JavaScript

## Vercel environment variables
SPORTSGAMEODDS_API_KEY
STRIPE_SECRET_KEY
STRIPE_PRICE_ID
SUPABASE_URL
SUPABASE_ANON_KEY
SUPABASE_SERVICE_ROLE_KEY

The app remains usable even before optional keys are configured.
